## Overview

Codefidence is my personal developer portfolio — a space to showcase my technical interests, selected engineering concepts, and approach to building reliable, user-focused applications.

The project combines clean visual design with reusable React components, responsive layouts, thoughtful interactions, and modern frontend development practices.

## Key Features

- **Responsive Design** — Layouts adapted for mobile, tablet, and desktop.
- **Light & Dark Themes** — Interactive theme switching with a consistent visual identity.
- **Reusable Components** — Modular navigation, project cards, and interface components.
- **Project Showcase** — Engineering concepts covering data interfaces, authentication architecture, and design systems.
- **Accessible Navigation** — Semantic structure, keyboard-friendly interactions, and mobile navigation.
- **Contact Integration** — Email, LinkedIn, GitHub, and WhatsApp contact links.
- **Production Deployment** — Hosted on Vercel with a custom domain.

## Tech Stack

| Technology | Purpose |

## Getting Started

Clone the repository:

```bash
git clone https://github.com/C4Confidence/codefidence.git
cd codefidence
```

Install dependencies:

```bash
npm ci
```

Start the development server:

```bash
npm run dev
```

Open **http://localhost:3000** in your browser.

### Available Commands

```bash
npm run dev      # Start development server
npm run build    # Create production build
npm run start    # Run production build
npm run lint     # Run ESLint
```
